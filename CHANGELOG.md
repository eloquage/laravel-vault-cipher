# Changelog

All notable changes to `laravel-vault-cipher` will be documented in this file.

## v0.1.7 - 2026-11-03

- Align Composer author and keyword metadata with Eloquage.

## v0.1.6 - 2026-11-03

Release the package with Composer identity under the eloquage vendor namespace. This release contains the package metadata and documentation rename; runtime behavior is unchanged.

README and package artwork update with tenant key-provider, string encryption, and encrypted file examples.

- Initial release of the refactored package.
- Modernized with `spatie/laravel-package-tools`.
- Added support for Laravel 11, 12, and 13.
- Improved test coverage and static analysis.
